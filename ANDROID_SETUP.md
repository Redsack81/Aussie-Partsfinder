# Android setup

This starter uses Flutter. Create a standard Flutter project with:
flutter create .

Then replace pubspec.yaml and lib/main.dart with the supplied files.

The project needs the `url_launcher` package. Flutter will add the required Android intent/query configuration during normal package setup.

Before publishing, add:
- privacy policy
- terms of use
- marketplace trademark/branding review
- analytics/crash reporting if desired
- app icon and screenshots
- Play Store listing
